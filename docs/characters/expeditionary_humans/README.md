# Terran Expeditionary Directorate Character Profiles

The Terran cast should show survival pressure turning into occupation, while still keeping the humans recognizably human: tired commanders, ruthless governors, overworked engineers, compromised scientists, civilians, archives, and soldiers trying to live with impossible orders.
