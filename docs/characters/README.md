# Character Profiles

This section contains named story characters for the RTS reboot direction. Character files are separate from race design docs so campaign writing, mission scripting, portraits, barks, and faction lore can evolve without overloading the core race pages.

## Factions

- [Aetherborn Concord](aetherborn/README.md)
- [Terran Expeditionary Directorate](expeditionary_humans/README.md)
- [The Inheritors](inheritors/README.md)

## Character File Pattern

Each character profile should include:

- Role
- Race/Faction
- Archetype
- Public Face
- Private Fear
- Character summary
- Story Function
- Conflict Hook
- Gameplay Tie
- Sample Line
