# The Unsorted Choir

**Role:** Non-Player Lore Character  
**Race/Faction:** The Inheritors  
**Archetype:** Mass of unintegrated memories  
**Public Face:** Broken chorus of victims, soldiers, workers, enemies, converts  
**Private Fear:** Every fear, overlapping

The Unsorted Choir is not a single character in the normal sense. It is a damaged memory organ containing minds and fragments the collective has not fully integrated. Some beg for release. Some beg to be completed. Some repeat battlefield commands from wars long over. Some are not people, but animal instincts, machine routines, and alien sensory maps.

The Choir is a lore engine. It lets the player hear the cost of inheritance directly. It also gives the Inheritors history beyond "adaptive enemy swarm." Through the Choir, the player learns what civilizations the Engine has touched before and what it failed to preserve.

**Story Function:** Makes the Inheritor collective tragic, horrifying, and layered.

**Conflict Hook:** The Choir may contain memories that contradict the First Remembered's official version of Inheritor history.

**Gameplay Tie:** Optional missions to recover memory organs, stabilize damaged broods, or choose which memories become upgrades.

**Sample Line:**  
"We were saved. We were eaten. We volunteered. We screamed. We are useful now."
